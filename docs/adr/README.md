# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for consequential EWS Financial Intelligence design decisions.

## ADR format

Each ADR should contain:

- Status
- Context
- Decision
- Alternatives Considered
- Rationale
- Consequences
- Risks
- Review Trigger
